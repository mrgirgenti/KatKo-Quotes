# Reports Page Redesign — Replace Current Version

The current Reports page is functional but does not match the dashboard design we previously approved.

The biggest issue is that the page relies heavily on tables. Reports should function as an executive dashboard, not a spreadsheet.

Do not make minor tweaks to the existing layout. Rebuild the Overview tab to match the structure below while preserving existing data calculations and filtering logic.

---

# Objective

The Reports page should quickly answer:

1. How is the business performing?
2. What is generating revenue?
3. What is generating profit?
4. What needs attention?
5. Where should I focus next?

The page should feel visual, actionable, and operational.

---

# Design Rules

Do NOT default to large tables.

Prioritize:

* KPI cards
* Summary cards
* Rankings
* Visual dashboards
* Actionable information

Reuse existing design language already built inside:

* Client Legacy
* Active Projects
* Submitted Quotes
* Dashboard KPI cards

The Reports page should feel like an executive dashboard for running the business, not an exported spreadsheet.
