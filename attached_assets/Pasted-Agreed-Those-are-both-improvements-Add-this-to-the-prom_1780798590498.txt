## OVERVIEW TAB PRINCIPLE

Overview should function as a dashboard summary.

Users should:

* Review project status
* Review quote status
* Review client history
* Review hub activity

* Organization Header
* Global Navigation
* Projects Page
* Quotes Page

This keeps the Overview tab focused on visibility instead of actions.
