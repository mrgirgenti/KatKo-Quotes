==================================================
CORE ARCHITECTURE
==================================================

The architecture of this system is now officially defined as follows:

Quote
    ↓
Line Item (Production Run / Design)
    ↓
Products

A Quote is a collection of production jobs.

A Line Item represents ONE production run (one design).

Products are individual garments/items that participate in that production run.

Products inside a Line Item share:

• artwork
• mockup
• decoration method
• decoration locations
• production calculator
• additional services
• production notes
• service cost
• production setup

Products differ only by:

• Product Type
• Product Style
• Color
• Size quantities
• Wholesale garment cost
• Product-specific selling price (future)

Examples:

40 Next Level 6210
10 Comfort Colors 1717

Same artwork.

Same screen print.

Same front/back locations.

Same production setup.

Same calculator.

Same production cost.

This is ONE Line Item.

However:

Design A

and

Design B

are TWO different production runs.

Therefore they are TWO Line Items.
