MEDIA BIN STANDARDIZATION PASS
==============================

OBJECTIVE

Create a single, unified Media Bin experience throughout Katalyst OS and Client Hubs.

Currently there are multiple Media Bin implementations that behave and display differently.

The goal is to create ONE shared media system used everywhere.

This task should NOT redesign unrelated pages.

This task should focus only on:

* Media display
* Media upload
* Media management
* Media selection
* Responsive behavior

==================================================
GLOBAL MEDIA BIN STANDARD
=========================

These standards apply everywhere media is displayed, selected, uploaded, managed, or referenced.

Applies to:

* Organization Details Media Bin
* Contact Media Bin
* Client Hub Dashboard Media Bin
* Client Hub Media Bin Page
* Media Picker Modal
* Project Artwork Attachments
* Future Web Stores
* Future Artwork Approval systems
* Future media-related modules

==================================================
PHASE 1
FIX ORGANIZATION DETAILS MEDIA BIN
==================================

Current issue:

Media exists and displays correctly on:

* Mobile
* Tablet

But does NOT display correctly on:

* Desktop/Web

This appears to be a rendering/layout issue rather than a data issue.

Investigate and fix.

Success criteria:

Organization Details Media Bin displays correctly on:

* Desktop
* Tablet
* Mobile

using the same card layout as all other media bins.

==============================

File Size

Required actions:

Delete

==================================================

Rename functionality

Current state:

Some locations allow download/delete but not rename.

Requirement:

Every media asset everywhere must be renameable.

Add pencil/edit action.

Behavior:

Click Rename

Inline edit field appears

Save

Cancel

No separate screen required.

==================================================
PHASE 5
EMPTY STATE STANDARD
====================

Whenever a Media Bin contains zero files:

Display the standard Katalyst Media Empty State.

Use the approved upload graphic currently being deployed.

Requirements:

* Orange background
* Approximately 10% lighter than brand orange (#FF5A00)
* Centered upload illustration
* Consistent spacing
* Consistent sizing

Display:

Drag and drop your media here

AI • SVG • PS • PNG • JPG • PDF • EMB • DST • PES

==================================================

This empty state should appear everywhere.

Applies to:

* Organization Details
* Contacts
* Client Hub Dashboard
* Client Hub Media Bin
* Media Picker
* Future Media Modules

==================================================

Do NOT create custom empty states.

Do NOT display:

"No files"

"No media"

"Empty"

"No uploads"

Use only the standardized Katalyst Media Empty State.
