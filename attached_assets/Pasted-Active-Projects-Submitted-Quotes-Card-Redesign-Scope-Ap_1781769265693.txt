Active Projects & Submitted Quotes Card Redesign

Scope

Apply these changes to:

* Active Projects
* Submitted Quotes

Do not modify:

* Metrics row
* Section headers
* Search functionality
* Revenue calculations
* Profit calculations
* Sorting logic
* Existing project links

Goal

Reduce excessive card height and whitespace while increasing information density and maintaining readability.

The new design should allow significantly more projects and quotes to be visible without scrolling.

Search & Filters

Current:

Search Bar
Quick Filter Pills underneath

Replace with:

Search Bar                        [ Filters ▼ ]

Requirements:

* Remove the quick filter pills entirely.
* Add a Filters button inline to the right of the Search field.
* Reuse the same filter interaction pattern established on the Production page.
* Maintain desktop and mobile responsiveness.

Visual Design

Keep existing:

* Black section headers
* Orange accent color
* Status badge styling
* Card styling
* Border radius
* Hover states

This is a refinement of the existing design, not a redesign.

Expected Outcome

Users should be able to:

* See more projects and quotes per screen.
* Scan project information faster.
* Maintain desktop/mobile consistency.
* Access filtering through a unified Filters button.
* Preserve all existing project data visibility while dramatically reducing wasted space.
