Client Hub Launch Readiness Sprint

This sprint focuses on preparing Client Hubs for real-world customer usage.

The objective is:

A customer should be able to:

* Log into their Client Hub
* Submit projects
* View projects
* Review quotes
* Review invoices
* View mockups
* Download files
* Understand project status

without seeing internal operational data.

STOP.

Do not work on:

* Vendor APIs
* Product Imports
* Color Imports
* Placement Templates
* Mockup Generation Enhancements
* Inventory Sync
* Pricing Sync

Those will be addressed in future phases.

This sprint is Client Hub only.

Audit:

My Projects

Submitted Projects

Completed Projects

Invoice History

Current issues observed:

* Pieces missing
* Totals missing
* Per Piece missing
* Project information not displaying consistently

Trace:

Database
↓
API
↓
DTO
↓
Client Hub
↓
Rendering

Fix root causes.

Do not hardcode values.

Required Result:

* Project Name
* Status

* Created Date
* Due Date
* Quote Status
* Invoice Status

when data exists.

## PHASE 3 — DASHBOARD / MY PROJECTS ALIGNMENT

Audit:

Dashboard Active Projects

My Projects Active Projects

* Duplicate logic exists
* Duplicate rendering exists
* Different data sources exist

Avoid duplicate implementations.

Avoid separate project card systems.

Maintain one source of truth.
