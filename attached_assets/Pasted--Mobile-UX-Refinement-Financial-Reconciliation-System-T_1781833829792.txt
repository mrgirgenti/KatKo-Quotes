# Mobile UX Refinement + Financial Reconciliation System

This is a refinement pass. Preserve existing functionality, branding, colors, navigation structure, and overall design language. Focus on usability, consistency, and operational workflow improvements.

---

# 1. Organizations Page Header (Mobile)

## Current Issue

The Organizations page header is the only page where the title and action buttons become crowded.

Current:

Organizations | Actions | Add Organization

The Add Organization button gets clipped and feels cramped.

## Requirements

Mobile only:

Change:

* Add Organization

To:

* Organization

Keep:

* Existing one-row layout
* Existing Actions button
* Existing spacing behavior used throughout the app

Goal:

Allow the page title and actions to fit comfortably without creating a unique mobile header pattern.

---

# 15. Financial Reconciliation Workflow

This is a new operational workflow.

---

## Financial Statuses

Add:

Needs Reconciliation
Reconciled

These are NOT project statuses.

They are financial statuses.

---

## Automatic Workflow

When Project Status becomes:

Completed

Automatically set:

Financial Status = Needs Reconciliation

---

## Reconciliation Action

Add action to Project dropdown:

Financial Reconciliation

Do NOT create a standalone button.

Keep it inside the Actions menu.

---

## Reconciled State

When user marks project as:

Reconciled

Automatically:

* Lock invoice financial information
* Prevent edits to:

  * Revenue
  * Costs
  * Fees
  * Profit
  * Quantities

This should leverage existing invoice locking behavior if already implemented.

---

## Unlock Workflow

Add action:

Unlock Reconciliation

Confirmation modal:

"This project has already been reconciled. Unlocking will remove the reconciled status and allow financial edits. Continue?"

If confirmed:

Financial Status = Needs Reconciliation

Invoice Locked = False

User can edit and reconcile again later.

---

## Reporting Queue

Inside Reports:

Add:

Tracking Queue

or

Reconciliation Queue

Display:

All completed projects with:

Financial Status = Needs Reconciliation

Goal:

Provide a centralized operational list for reviewing actual profitability.

---

# 16. Future-Proofing Note

The purpose of reconciliation is to compare:

* Estimated quote profitability
* Actual project profitability

and establish a reliable source of truth for business reporting.

The reconciled values should be treated as the final financial record for that project.
