## PART 1 — Vendor Architecture Expansion

Business Definition

A Vendor represents a sourcing partner.

Examples:

* S&S Activewear
* SanMar
* McCreary's
* Shaka Wear
* Independent Trading
* LA Apparel
* Momentec
* Otto Caps

A Vendor may provide:

* Website
* Catalog
* Product Data
* Colors
* Pricing
* Inventory
* API Access

Vendor records become the foundation for future:

* Product Imports
* Color Imports
* Pricing Imports
* Inventory Imports
* API Integrations

Step 1

Audit Vendor schema and UI.

Return:

* Current fields
* Missing fields
* Future limitations

Step 2

Expand Vendor records to support:

General

* Name
* Active
* Notes

Links

* Website URL
* Catalog URL

Future Integration

* API Enabled
* API Provider
* API Status
* Import Enabled
* Product Import Enabled
* Color Import Enabled
* Pricing Sync Enabled
* Inventory Sync Enabled
* Last Sync Date

Do not build integrations.

Only prepare the architecture.
