Implement only the pricing-drift guard for multi-product line items.

Goal:
Prevent silent wrong totals if a future feature introduces per-product serviceCostEach, serviceFeeEach, or markupEach that diverges from the Line Item-level values.

Current rule:
For now, serviceCostEach, serviceFeeEach, and markupEach are Line Item-level values shared across all products/garments in the Line Item.

Product-level differences are NOT currently supported for:
- serviceCostEach
- serviceFeeEach
- markupEach

Only productCostEach may differ by product.

Tasks:

- product.serviceCostEach must match lineItem.serviceCostEach if present
- product.serviceFeeEach must match lineItem.serviceFeeEach if present
- product.markupEach must match lineItem.markupEach if present

2. If divergence is found, fail loudly.

Preferred behavior:
Throw an explicit error with a clear message, such as:

"Multi-product line items do not support per-product serviceCostEach, serviceFeeEach, or markupEach. These values must remain shared at the Line Item level."

- Products share production/service/fee/markup costs at the Line Item level.
