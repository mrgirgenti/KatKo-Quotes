## GLOBAL TABLE SYSTEM

Katalyst OS currently has inconsistent table layouts.

Each page appears to be handling column sizing independently.

This is creating recurring problems across:

* Organizations
* Contacts
* Quotes
* Projects
* Production
* Reports
* Client Hub tables

We need a reusable table sizing system.

---

## OBJECTIVE

Create a shared table layout standard.

Future tables should inherit consistent sizing behavior rather than requiring page-by-page fixes.

---

## LAYOUT RULES

Do NOT use equal-width columns.

Do NOT use fully flexible layouts that allow important columns to collapse.

Use intentional widths.

Example:

Project
Status
Date
Date
PCS
Total
Action

Should not distribute equally.

---

## RESPONSIVE BEHAVIOR

Desktop:

Maintain intentional sizing.

Tablet:

Maintain intentional sizing.

Mobile:

Horizontal scrolling is acceptable.

Do not compress columns until unreadable.

---

## SUCCESS CRITERIA

A user should immediately be able to scan:

* Names
* Statuses
* Dates
* Revenue
* Profit
* Actions

without columns feeling crowded, uneven, or randomly spaced.

This system should become the standard used throughout Katalyst OS and Client Hubs going forward.
