4. RESPONSIVE RULES
======================================================================

Tables:
- should not crush columns into unreadable text
- use horizontal scroll where necessary
- important actions must remain accessible
- status badges should not wrap awkwardly
- multi-line rows should remain readable

Cards:
- should stack cleanly on mobile
- spacing should remain consistent
- text should not overflow
- buttons should remain visible

Forms:
- fields should stack logically on mobile
- labels should remain readable
- input widths should be consistent
- size/quantity grids should not hide XS or any size columns
- horizontal scroll is acceptable for dense size grids

Buttons:
- should not overlap
- should not be too small for touch
- primary actions should remain easy to find
- destructive actions should be visually clear

Headers:
- titles should not wrap awkwardly if avoidable
- badges should align cleanly
- section headers should use consistent widths and spacing

Dropdowns / Ellipsis menus:
- must anchor next to or below the trigger
- must not open on the far side of the screen
- must stay within viewport bounds
- must work on mobile/tablet

Modals:
- should fit within viewport
- should scroll internally if content is tall
- buttons should remain accessible
- no content should be clipped

Navigation:
- sidebar/mobile nav should behave correctly
- active states should remain clear
- profile area should remain accessible
