CATALOG MANAGEMENT REFACTOR

The current architecture of Catalogs is incorrect.

Wholesale Vendors and Client-Facing Catalogs should NOT exist as separate pages or tabs.

They are the same vendors.

The difference is only whether a catalog is visible inside Client Hubs.

--------------------------------------------------
REMOVE
--------------------------------------------------

Remove:

- Wholesale Vendors tab
- Client-Facing Catalogs tab

Replace with:

Single Catalog Management page.

--------------------------------------------------
NEW VENDOR STRUCTURE
--------------------------------------------------

Each vendor record should contain:

- Vendor Name
- Description
- Category
- Logo
- Website URL
- Catalog URL

Visibility Settings:

- Visible In Client Hub (toggle)
- Featured Vendor (toggle)

When Visible In Client Hub is ON:

Show Catalog URL inside all Client Hubs.

When OFF:

Vendor remains internal only.

No duplicate vendor records should exist.

--------------------------------------------------
MOBILE LAYOUT FIXES
--------------------------------------------------

Current mobile layout has significant dead space on the right side.

Maintain:

- 2-column layout

Fix:

- Remove unused right-side space
- Stretch cards evenly across available width
- Use full container width

Target:

48% card width
4% gap
48% card width

Cards should fill available space.
