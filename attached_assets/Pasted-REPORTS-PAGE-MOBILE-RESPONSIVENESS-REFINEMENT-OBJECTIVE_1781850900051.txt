REPORTS PAGE — MOBILE RESPONSIVENESS REFINEMENT

OBJECTIVE

The Reports page has been structurally improved, but the mobile experience feels crowded, compressed, and difficult to scan.

The goal is NOT to redesign the Reports page.

The goal is to improve readability, spacing, hierarchy, and usability on mobile while preserving the existing desktop layout.

Apply these improvements consistently across ALL Reports tabs:

* Overview
* Financial
* Customers
* Services
* Exports

---

## GLOBAL MOBILE RULES

Target widths:

Mobile:
320px–768px

Tablet:
769px–1024px

On mobile:

* Prioritize readability over density.
* Avoid compressed multi-column tables.
* Do not allow text collisions.
* Do not allow columns to run together.
* Do not allow labels to wrap into awkward multi-line stacks.
* Preserve black section headers.
* Preserve orange actions.
* Preserve Katalyst OS spacing standards.

---

## TAB NAVIGATION

Current issue:

The tab bar becomes cramped.

Required changes:

* Increase horizontal padding.
* Allow horizontal scrolling.
* Keep tabs on a single row.
* Never wrap tabs onto a second line.
* Active tab remains orange.
* Preserve current visual styling.

Example:

Overview | Financial | Customers | Services | Exports

Should scroll horizontally if necessary.

## TABLE RESPONSIVENESS STANDARD

For ALL Reports tabs:

Desktop:
Keep tables.

Mobile:
Convert tables into cards.

DO NOT horizontally compress tables.

DO NOT reduce font sizes to force tables to fit.

DO NOT truncate critical data.

Instead:

Transform rows into stacked information cards.

This pattern is already used successfully elsewhere in Katalyst OS and should be reused here.

---

## TYPOGRAPHY

Increase readability:

Section Header Titles

* Slightly larger

Table/Card Labels

* Medium weight

Primary Values

* Larger
* Easier to scan

Maintain existing brand styling.

---

## SUCCESS CRITERIA

After implementation:

* No overlapping text
* No merged column headers
* No unreadable tables
* No horizontal crowding
* No awkward wrapping
* Consistent spacing
* Consistent mobile card layouts
* Reports page feels native to Katalyst OS

The mobile Reports experience should prioritize readability and scanning speed over showing traditional desktop tables.
