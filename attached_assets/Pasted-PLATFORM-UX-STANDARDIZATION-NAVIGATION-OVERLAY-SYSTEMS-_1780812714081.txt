==================================================
PART 2 — PLATFORM OVERLAY / DROPDOWN SYSTEM
===========================================

Current behavior:

Dropdowns and action menus are rendering behind page content.

Example:

Organization Actions menu.

Menu appears beneath:

* headers
* cards
* content containers

This is a platform-level bug.

==================================================
REQUIREMENT
===========

Create a consistent overlay layering system.

Audit:

* Actions menus
* Status dropdowns
* Filters
* Date pickers
* Popovers
* Context menus
* Future dropdown components

==================================================
STACKING ORDER
==============

Required hierarchy:

Modals

Dropdowns / Popovers

Page Content

Nothing should render above a dropdown except a modal.

==================================================
INVESTIGATE
===========

Review:

* z-index
* stacking contexts
* overflow hidden containers
* relative positioning
* portal rendering

Fix root cause.

Do not apply one-off z-index patches.

SUCCESS CRITERIA
