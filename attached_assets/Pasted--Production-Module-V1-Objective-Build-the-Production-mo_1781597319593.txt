# Production Module V1

## Objective

Build the Production module as the operational command center of Katalyst Ko OS.

This is where production staff, managers, and owners monitor, prioritize, and execute active work.

This is NOT a CRM page.

This is NOT a reporting page.

This is NOT a quote management page.

The Production module should answer:

* What should we work on next?
* What is currently in production?
* What is blocked?
* What is due soon?
* What is behind schedule?
* What capacity do we have left?

All production views should operate from the same underlying project data.

No duplicated records.

No separate production projects.

A project exists once and can be viewed through multiple production layouts.

---

# Navigation

Operations

* Projects
* Production

Projects remains the source of truth.

Production is a specialized operational view of projects.

Clicking any project in Production should open the existing Project Detail page.

Do not create a separate project-detail experience.

---

# View Modes

The Production page should support multiple view modes.

Users may select their preferred view.

Users may set a default production view in Profile / Settings.

The system remembers the user's last selected view.

Views:

1. Board
2. Queue
3. Calendar
4. Analytics

---

# Shared Filters

All views share the same filtering system.

Filters:

* All Projects
* Service Type
* Operational Status
* Priority
* Assigned User
* Due Date Range
* Delivery Method

Search:

* Project Name
* Organization
* Project Number

Filters persist when switching views.

---

# Priority System

Add a dedicated Priority field.

Priority is independent from Status.

Priority answers:

"How important is this project?"

Status answers:

"Where is this project?"

Priority Options:

Critical
High
Normal
Low

Default:

Normal

Display:

Critical = Red
High = Orange
Normal = Blue
Low = Gray

Projects should sort by:

1. Priority
2. Due Date

A Critical project due tomorrow should appear before a Normal project due next week.

# Production Data Source

Production only displays projects with operational statuses:

Accepted
Awaiting Artwork
Artwork Approval
Awaiting Payment
Ready for Production
In Production
On Hold
Completed
Delivered

Exclude:

Draft
Quoted
Expired

Those remain inside Quotes.

Production begins only after a project enters the operational workflow.

---

# Project Integration

Every production card, row, event, and analytics record should link directly to the existing Project Detail page.

No duplicate detail screens.

No separate production project pages.

The existing Project Detail page remains the management hub.

Production is simply a different lens into project data.

# Success Criteria

A production manager should be able to:

* Open Production
* Instantly identify the highest-priority jobs
* See what is currently running
* See what is blocked
* See what is due next
* Open any project in one click

without ever leaving the Production module.
