Do NOT proceed to Navigation Restructure (Phase 2) until this work is completed and verified.

This phase focuses on:

* Organization Detail usability
* Active Projects
* Submitted Quotes
* Project Numbering

* Navigation
* CRM visibility

This is NOT a redesign.

This is a refinement and completion of the approved Organization experience.

---

## ACTIVE PROJECTS & SUBMITTED QUOTES

### Core Requirement

Both sections must use the EXACT SAME CARD STRUCTURE.

Currently:

* Active Projects uses one layout.
* Submitted Quotes uses a different layout.

This must be corrected.

The user should immediately recognize both sections as related.

Only the data changes.

The layout remains identical.

---

## CARD LAYOUT

Each card should use a compact 3-row structure.

Example:

```text
#1

P-1002

[In Production] Team Shirts                     Order: Apr 12

Due: Apr 30      Direct to Film      37 pcs

Total: $511.45                       Profit: $74.00
```

### Display Requirements

Every Active Project and Submitted Quote card must display:

* Project Number
* Status
* Project Name
* Order Date
* Due Date
* Service
* Qty
* Total
* Profit

Profit must ALWAYS display.

Examples:

Profit: $0.00

Profit: $74.00

Profit: $128.45

Do not hide profit when it equals zero.

## SORTING LOGIC

IMPORTANT:

The Organization page is a CRM view.

It is NOT a production management view.

We process work FIFO.

Clients already understand our turnaround requirements.

Default sorting should reflect operational reality.

### Active Projects

Default Sort:

Order Date

Oldest First

Purpose:

Process projects in order received.

### Submitted Quotes

Default Sort:

Submission Date

Oldest First

Purpose:

Process quotes in order received.

### Due Dates

Due Dates remain:

* Visible
* Searchable
* Filterable

However:

Due Dates should NOT control default sorting.

Production scheduling belongs in:

* Projects
* Production

not inside the Organization dashboard.

* Relationship Management
* Client Visibility
* Project Visibility

* Communication Visibility

* Production Scheduling
* Shop Floor Management

Projects

and eventually:

The Organization page should provide visibility and quick access, not production queue management.
