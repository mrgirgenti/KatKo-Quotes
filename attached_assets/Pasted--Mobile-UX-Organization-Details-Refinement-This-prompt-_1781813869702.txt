# Mobile UX & Organization Details Refinement

This prompt contains multiple approved UI refinements. Implement all changes together.

---

## Edit #1 — Active Projects & Submitted Quotes (Mobile Cards)

### Scope

Applies ONLY to:

* Organization Details → Active Projects
* Organization Details → Submitted Quotes
* Contact Details → Active Projects
* Contact Details → Submitted Quotes

Do NOT modify:

* Projects page
* Production page
* Quotes page

### Current Problem

Desktop cards were redesigned successfully, but mobile cards are still using the old layout.

Mobile should not have a separate card architecture.

It should be a responsive version of the new desktop card design.

### Requirements

Mobile cards should preserve the same hierarchy as desktop:

* Project Number
* Status Badge
* Project Name
* Client + Service
* Due Date
* PCS
* Revenue
* Profit

Use the desktop design as the source of truth.

Do not use the legacy stacked mobile layout.

Goal:

Desktop and mobile should feel like the same component.

## Edit #2 — Project Workflow Section (Project Details)

### Scope

Applies to:

* Project Details page
* Mobile and Desktop

### Current Problem

The current workflow card lacks hierarchy.

Status, Priority, Delivery, Indicators, and Actions all compete visually.

### Desired Hierarchy

1. Status
2. Actions
3. Priority
4. Delivery Method
5. Readiness Indicators

### Requirements

Status should become the primary visual element.

Actions should visually relate to Status.

Delivery should be grouped with Priority.

Indicators should read as readiness indicators, not project statuses.

Current indicators:

* Payment
* Artwork
* Proof

Should remain informational and non-blocking.

Improve spacing, grouping, and hierarchy.

Do not remove functionality.
