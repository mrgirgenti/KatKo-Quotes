Actions:

* Resend Invite for invited users
* Promote to Admin
* Remove User
* Optional dropdown for row actions

Important business logic:

When an Org Admin invites a user from Client Hub Team Management:

1. Create or update a Contact in the main Katalyst OS Organization Details contact section.
2. Link that contact to the correct Organization.
3. Enable Client Hub access for that contact.
4. Send the Client Hub invitation.
5. Display the invited user in Team Management with status Invited.

This prevents duplicate work between Client Hub users and Organization Contacts.

If the contact already exists:

* Do not create duplicate contact.
* Update existing contact to enable Client Hub access.
* Send or resend invite.

If user is removed:

* Remove Client Hub access.
* Do not delete the Contact record from the Organization unless existing app behavior already supports that explicitly.
