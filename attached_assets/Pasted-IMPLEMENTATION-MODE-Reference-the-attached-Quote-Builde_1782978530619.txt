OBJECTIVE
====================================================

The Products + Sizes section should become the definitive workspace for defining WHAT is being decorated.

This section is NOT responsible for pricing.

This section is NOT responsible for production costs.

Its only responsibility is defining the products participating in this production run.

====================================================
ARCHITECTURE
====================================================

Maintain the current business rule.

One Line Item represents ONE production run.

Multiple Products may exist within a Line Item ONLY when they share:

• artwork
• decoration method
• decoration locations
• production setup
• production calculator
• production pricing

Products inside the Line Item may differ ONLY by:

• Product Type
• Product Style
• Product Color
• Size Quantities

Do NOT change this architecture.
