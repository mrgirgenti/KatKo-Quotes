# PHASE 1 — ORGANIZATION / CRM EXPERIENCE REFINEMENT

Objective:

Improve the Organization experience, CRM usability, Client Hub management, project visibility, and navigation consistency without redesigning the platform.

IMPORTANT:

Do NOT redesign the platform.

Do NOT create a new design language.

Do NOT move major sections around unnecessarily.

Preserve the existing structure and styling language already established throughout the OS.

======================================================================
ORGANIZATION HEADER REFINEMENT
==============================

The Organization header currently feels oversized and inefficient.

Changes:

1. Increase organization profile/logo image approximately 30%.

2. Reduce size of:

* Active Client pill
* New Quote button

3. Replace current Organization action controls with a cleaner pattern similar to:

* Contacts page
* Vendors page

Desired actions:

New Quote

Actions ▼

Actions menu:

* Edit Organization
* Add Contact
* Invite Hub User
* Upload Media
* View Client Hub
* Generate Invoice
* View Activity
* Divider
* Delete Organization

Keep visual styling consistent with existing pages.

======================================================================
SIDEBAR PERSISTENCE
===================

Currently it is difficult to move between areas when inside:

* Organization
* Contact
* Project

The main OS sidebar should remain available throughout these views.

Users should never feel trapped inside a record.

Maintain current sidebar styling.

Do not redesign.
