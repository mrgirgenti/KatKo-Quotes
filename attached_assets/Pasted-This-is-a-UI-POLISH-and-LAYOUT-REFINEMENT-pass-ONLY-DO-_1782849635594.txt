====================================================
OVERALL OBJECTIVE
====================================================

The expanded Line Item should feel like one cohesive production workspace.

It should NOT feel like four separate cards stacked together.

The goal is to make the UI feel calmer, cleaner, more premium, and significantly easier to scan during all-day quoting.

No functionality changes are required unless specifically listed below.

====================================================

The Design Details section currently feels cramped and compressed.

Adjust the internal layout to improve readability.

Specifically:

• Increase the usable width of text inputs wherever possible.
• Use whitespace to create logical groups instead of making every field feel equally important.
• Increase spacing between groups of related fields.

Group the section visually into:

DESIGN
- Design Name
- Project Notes

PRODUCTION
- Service Style
- Product Source
- Priority

LOCATIONS
- Decoration Locations

ADDITIONAL SERVICES
- Additional Services

Do NOT add new cards or accordions.

Simply improve spacing and organization.

----------------------------------------------------

Move "Additional Services" below Locations instead of trying to fit it beside other fields.

This section should stack vertically.

Doing this frees additional horizontal room for the rest of the Design Details inputs.

====================================================
2. SECTION SPACING
====================================================

The page currently feels boxed-in.

Every section begins immediately underneath the previous one.

Specifically add approximately:

• 16px above each black section header
• 12px below each black section header

Apply consistently to:

• Design Details
• Products + Sizes
• DTF Cost Calculator
• Line Item Costs
