Production Module Redesign — Queue + Calendar Workflow Experience

STOP.

Do not audit.

Do not roadmap.

Do not iterate on the existing table.

This is a full redesign of the Production module's Queue and Calendar views.

The attached mockup is now the source of truth.

The current Queue view is a CRM table pretending to be a production system.

That architecture is fundamentally wrong.

We are replacing it with a production-first workflow built specifically for an apparel print shop.

The existing Production Board view can remain for now.

This sprint is ONLY:

• Queue
• Calendar

====================================================
OVERALL GOAL
====================================================

Production is not CRM.

Production is not Sales.

Production is not Accounting.

Production exists for one purpose:

Help production staff quickly determine:

• What needs produced
• In what order
• Using which artwork
• On which garments
• By what due date
• Using what production method

Every design decision should support those goals.

====================================================
QUEUE VIEW
====================================================

Replace the current spreadsheet table.

Do NOT simply enrich the existing table.

Build the Queue using production workflow cards grouped chronologically.

Structure:

TODAY

Project Card

------------------------------------------------

TOMORROW

Project Card

------------------------------------------------

NEXT 7 DAYS

Project Card

------------------------------------------------

ON HOLD

Project Card

------------------------------------------------

OVERDUE

Each section should collapse/expand independently.

Display badge counts beside each section title.

====================================================
PROJECT CARD
====================================================

Every project card should span the available width.

Cards should feel like production work orders.

LEFT SIDE

• Primary Mockup
• Additional mockup count badge
• Project Number
• Project Name
• Organization
• Service Type icon + label
• Total Quantity
• Garment Size Range

+3 Mockups

using the existing mockup hierarchy.
