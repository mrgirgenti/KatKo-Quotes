# PART 1 — QUOTES VS PROJECTS LIFECYCLE

The current system is incorrectly allowing quote-stage records to appear in Projects.

A project request submitted through Client Hub should create a Quote Request.

It should NOT appear in Projects.

---

## QUOTES PAGE

The Quotes page should contain:

DRAFT

NEEDS_REVIEW

QUOTING

QUOTED

INVOICE_SENT

These are all quote-related states.

---

## PROJECTS PAGE

The Projects page should contain:

PAID

IN_PRODUCTION

COMPLETED

These are actual projects.

---

## REQUIRED FIX

A Client Hub submission currently creates:

NEEDS_REVIEW

This record is appearing in Projects.

This is incorrect.

NEEDS_REVIEW records belong in Quotes.

Only actual projects belong in Projects.

Implement the separation.
