Katalyst OS – Mobile UX, Production Workflow, Catalog Management & Design System Overhaul

Objective

We have reached a point where individual features are working, but the overall system lacks consistency across mobile, tablet, and desktop experiences.

The goal of this project is NOT to add more features immediately.

The goal is to establish a unified design system, improve operational workflows, eliminate UI inconsistencies, and create scalable management systems that can support future growth without introducing additional technical debt.

This project should be completed in phases in the order listed below.

⸻

PHASE 1 – DESIGN SYSTEM & RESPONSIVE UX STANDARDIZATION

Goal

Create a unified design language across the entire OS.

Currently:

* Contacts looks different from Projects
* Projects looks different from Catalogs
* Client Hub differs from Backend
* Mobile layouts feel cramped
* Cards, buttons, filters, headers, and metrics all use different sizing rules

We need a reusable design system.

⸻

Create Global Standards For

Typography

Define standard sizing for:

* Page Titles
* Section Headers
* Card Titles
* Labels
* Body Text
* Helper Text
* Status Pills

These standards should apply consistently across:

* Contacts
* Projects
* Quotes
* Production
* Catalogs
* Client Hubs
* Future Modules

⸻

Spacing

Define global spacing rules:

* Card padding
* Section spacing
* Header spacing
* Filter spacing
* Mobile spacing
* Tablet spacing
* Desktop spacing

Avoid:

* cramped layouts
* excessive whitespace
* inconsistent margins

⸻

Buttons

Standardize:

Primary Action
Examples:

* New Quote
* Add Contact
* Submit Project

Secondary Action
Examples:

* Edit
* View
* Export

Danger Action
Examples:

* Delete

Button heights and widths should be consistent throughout the application.

⸻

Status Pills

Standardize:

* Active Client
* Cold
* Working
* Quoted
* In Production
* Completed
* Paid
* Client Hub Live

Consistent:

* sizing
* spacing
* typography
* colors

⸻

Cards

Create reusable card standards:

* Contact Cards
* Project Cards
* Vendor Cards
* Quote Cards
* Media Cards

All cards should share:

* border radius
* padding
* spacing
* typography hierarchy

⸻

Headers

Introduce stronger visual hierarchy.

Mobile currently suffers from too much white-on-white layout.

Add stronger separation between:

* Page Header
* Filters
* Content

Recommendation:

Use black header bars with white text for:

* Contacts Table Header
* Projects Header
* Catalog Sections
* Media Sections

This creates visual separation and improves readability.

PHASE 3 – PRODUCTION WORKFLOW OVERHAUL

Improve production navigation for invoices containing multiple line items.

Current Problem

Production is unclear when:

* Item 1
* Item 2
* Item 3

⸻

New Production Navigation

Display:

Production Item X of Y

Examples:

Production Item 1 of 3
Production Item 2 of 3
Production Item 3 of 3

⸻

Navigation Controls

Desktop:

Previous
Next

Mobile/Tablet:

Swipe support

Users should be able to:

* swipe between production items
* move forward
* move backward

without returning to Projects.

⸻

Completion Logic

Single Item:

Complete
→ Return to Projects

Multiple Items:

Final Item:

Complete Item

Progress indicator

FINAL OBJECTIVE

Create a professional, scalable operating system that feels consistent across:

* Desktop
* Tablet
* Mobile

Every page should feel like it belongs to the same application.

Prioritize:

1. Consistency
2. Readability
3. Operational speed
4. Mobile usability
5. Long-term maintainability

Do not simply patch individual screens.

Establish reusable systems, components, and standards that future modules automatically inherit.
