====================================================
ARCHITECTURE GOALS
====================================================

The purpose of this task is to separate application configuration from application usage.

The Quote Builder should consume Production Settings.

It should never contain configuration logic itself.

Examples:

Vendor lists

Pricing presets

Default rates

Default calculator behavior

Rush defaults

Future pricing matrices

All belong inside Production Settings.
