OBJECTIVE

--------------------------------------------------
1. REMOVE DEAD SPACE BETWEEN LIST AND DETAIL PANEL
--------------------------------------------------

Current issue:

There is a large empty vertical column between the action list and the detail panel.

This space serves no purpose.

Currently:

Action List
        [huge empty gap]
                    Detail Panel

Desired:

Action List            Detail Panel

The action list should expand horizontally and consume all available space up to the detail panel.

The detail panel should sit directly beside the list.

No spacer column.

No unused flex area.

No dead space.

Audit the layout containers and remove any width allocations creating this gap.

--------------------------------------------------
2. MOVE DETAIL PANEL UP
--------------------------------------------------

Current issue:

The detail panel begins lower on the page than the action list.

This creates unnecessary dead space above the panel.

The detail panel should align vertically with the top of the action list.

Reference the approved mockup.

The list and panel should visually start at the same position.

--------------------------------------------------
3. METRIC SECTION BACKGROUND
--------------------------------------------------

Current issue:

Use the same light-grey metric-section treatment used elsewhere:

- Dashboard
- CRM
- Projects
- Organization Details

The metric area should visually belong to the platform.

Do not invent a new styling system.

--------------------------------------------------
4. METRIC CARD HEIGHT CONSISTENCY
--------------------------------------------------

Current issue:

Long labels wrap inconsistently.

Example:

Needs Review

vs

Customer Requests

causing uneven card heights.

Requirements:

- All cards must always be the same height
- All counts align
- All labels align
- All cards visually balanced

- Intentionally stack labels
- Use fixed-height cards
- Constrain label regions

But never allow card heights to vary.
