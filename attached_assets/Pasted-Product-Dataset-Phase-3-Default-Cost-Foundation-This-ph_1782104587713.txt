Architecture Reminder

Catalogs
↓
Products
↓
Quotes
↓
Projects
↓
Mockups
↓
Production

Products contain operational defaults.

Quotes contain snapshots.

Products should provide starting values.

Quotes own values after creation.

Snapshot Rule (Mandatory)

Products contain:

* Default Cost
* Preferred Catalog
* Placement Template
* Product Metadata

When a Product is selected:

Products supply the initial defaults.

After the Quote Line Item is created:

The Quote owns its own values.

Product changes must never retroactively modify:

* Existing Quotes
* Existing Projects
* Existing Orders
* Existing Mockups

Example

Product:

NL6210

Default Cost:
$4.50

Quote #1001 created.

Quote line item receives:

Cost:
$4.50

User edits quote:

Cost:
$4.85

Later:

NL6210 Product Cost changes to:

$5.10

Result:

Quote #1001 remains:

$4.85

Future quotes receive:

$5.10

This behavior is mandatory.
